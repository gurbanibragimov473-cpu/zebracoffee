# Zebra Coffee — personal portfolio concept

A responsive, multi-page cafe website concept inspired by Zebra Coffee. This independent project was built to practise front-end development with HTML, CSS and vanilla JavaScript.

## Pages and features

- Home page with a photo gallery and featured sections
- Interactive menu with categories, item customization, serving sizes and discount calculations
- Cafe locations with links to directions in 2GIS
- Brand founder story and loyalty-program information
- Demo careers form with an explanation that submissions are not sent or stored
- Shared language selector with English as the default, plus Russian and Kazakh; the selected language is saved in the browser. The language choice applies across all pages, including dynamically generated menu items, address cards, form options and dialogs
- Responsive layout for desktop and mobile screens

## Run locally

Open `index.html` in a modern browser. The project uses static HTML, CSS and JavaScript and does not require a build step or server. Google Fonts and external map, app-store and social links need an internet connection.

## Project structure

- `index.html`, `menu.html`, `addresses.html`, `about.html`, `zebra-coins.html`, `job.html`, `creators.html` — site pages
- `styles.css` — shared styling and responsive layout
- `menu.js` — interactive menu data and behavior
- `i18n.js` — shared language selector and client-side translations
- `images/` — image and icon assets
